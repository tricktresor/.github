# Tricktresor 🔐

**ABAP tools, experiments and tricks – straight from the SAP trenches.**

Small, practical open-source utilities for SAP developers. Every repo is a solution to a real problem – or a playground to understand one.

📖 Blog & articles: [tricktresor.de](https://tricktresor.de) · 📍 Hamburg, Germany

## Highlights

| Project | What it does |
|---|---|
| [**zapcommander**](https://github.com/tricktresor/zapcommander) | Norton-Commander-style file manager for SAP systems |
| [**gladius**](https://github.com/tricktresor/gladius) | Learn and challenge yourself with the ABAP Unit Test Framework |
| [**guidrasil**](https://github.com/tricktresor/guidrasil) | GUI designer for rapid prototyping in ABAP |
| [**splitstorm**](https://github.com/tricktresor/splitstorm) | Analyze, save, load & restore splitter configurations |
| [**class_inspector**](https://github.com/tricktresor/class_inspector) | Inspect ABAP classes |
| [**multiple_selections**](https://github.com/tricktresor/multiple_selections) | Variations of multiple selections |

➡️ [All repositories](https://github.com/orgs/tricktresor/repositories)

## Get started

Most repos can be installed via [abapGit](https://abapgit.org).
Found a bug or have an idea? Open an issue or start a [discussion](https://github.com/orgs/tricktresor/discussions) – pull requests welcome.
